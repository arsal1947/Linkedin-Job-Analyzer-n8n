# LinkedIn Job Analyzer — n8n Automation Workflow

An intelligent job-hunting automation pipeline that scrapes LinkedIn job listings based on your search criteria, analyzes each job against your resume using **Groq AI**, and saves structured results (with match scores and recommendations) directly to **Google Sheets** — all triggered by a simple form submission.

---

## ⚙️ Workflow Overview

```
Form Submission → Extract Resume (PDF) → Fetch Jobs (Apify) → Loop Over Jobs
    → Edit Fields → Groq AI Analysis → Wait → Format Results → Save to Google Sheets
```

## 🚀 Features

- 📄 **Resume Parsing** — Extracts text from your uploaded PDF resume automatically
- 🔎 **LinkedIn Scraping** — Fetches up to 10 live job listings by keyword + location via Apify
- 🤖 **AI-Powered Matching** — Groq LLaMA analyzes each job against your resume and returns:
  - `Match Score` (0–100)
  - `Reason` (why you are or aren't a good fit)
  - `Should Apply` (true / false recommendation)
- 📊 **Google Sheets Output** — Results saved with columns: Job Title, Company, Job Link, Posted At, Match Score, Reason, Should Apply
- ⏱️ **Rate-Limited Looping** — Built-in Wait node prevents API throttling during batch processing

## 🧠 How the AI Matching Works

For each scraped job, the workflow sends the job description + resume text to **Groq's LLaMA model** with a structured prompt. The model returns a JSON object containing:

```json
{
  "match_score": 85,
  "reason": "Strong background in AI/ML engineering and LangChain",
  "should_apply": true
}
```

This data is then formatted and appended to Google Sheets via the `appendOrUpdate` operation.

## 📦 Setup & Usage

### Prerequisites
- n8n instance (cloud or self-hosted)
- [Apify](https://apify.com) account + API key
- [Groq](https://console.groq.com) API key
- Google Sheets connected to n8n via OAuth

### Steps

1. **Import the workflow**
   - In n8n, go to **Workflows → Import from File**
   - Upload `linkedin-job-analyzer.json`

2. **Configure credentials**
   - Add your **Apify API key** in the HTTP Request node (Apify actor call)
   - Add your **Groq API key** in the HTTP Request1 node
   - Connect your **Google account** for the Sheets node

3. **Set up your Google Sheet**
   - Create a sheet with columns: `Job Title`, `Company`, `Job Link`, `Posted At`, `Match Score`, `Reason`, `Should Apply`
   - Link the sheet ID in the **Append or update row** node

4. **Trigger the workflow**
   - Open the form URL generated by n8n
   - Enter: Job Title (keyword), Location, and upload your Resume PDF
   - Hit submit — results appear in Google Sheets within minutes ✅
